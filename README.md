# Aaron Douglas Ng — Photography

My portfolio site. Three photobooks (About, Black & White, Color) that open into galleries.

The site rebuilds itself on GitHub Pages a minute or two after any change. Photos are
resized for the web and stripped of camera/location data automatically.

To add, reorder, move or delete photos from a phone or computer, open
https://aaronnewie.github.io/aaron-douglas-ng-photography/edit.html
