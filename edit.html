Edit your site

This page edits your photos on GitHub directly. Connect it once on each phone or computer with a GitHub key that can only touch this site.

  1. Open GitHub → New fine-grained token (sign in if asked).
  2. Name it anything, e.g. Site editor. Set Expiration as long as you like.
  3. Under Repository access choose Only select repositories → aaron-douglas-ng-photography.
  4. Under Permissions → Repository permissions set Contents to Read and write. Optional: Actions to Read-only, so the editor can tell you when the site is live.
  5. Press Generate token, copy it, and paste it below.

The key stays in this browser only. Anyone without it can open this page but can't change anything.
